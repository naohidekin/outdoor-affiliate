# コットとインフレーターマットはどっち？家族キャンプの選び方と併用の注意点

公開URL: https://camp-gear-lab.com/articles/cot-vs-mat-comparison

概要: コットとインフレーターマットを、家族分の幅・収納・設営撤収・断熱性で比較。WAQとコールマンの仕様を確認し、子どもと使うときや併用時の注意点も整理します。

コットとインフレーターマットで迷ったら、**地面から離れて寝たいのか、家族分の寝床を低い位置に並べたいのか**を先に決めましょう。そのうえで、テント内の幅・高さ、家族分の収納量、寒さへの備えを比べます。

コットは脚のある簡易ベッド。インフレーターマットは、フォームと空気を使って体を支える寝具です。どちらが快適かは、体格、寝る姿勢、硬さの好み、使う場所によって変わります。この記事は公開仕様と構造に基づく比較で、掲載製品を同条件で実測した寝心地ランキングではありません。

## 先に決めるなら、この基準で

| 困っていること・使い方 | 最初に検討するもの | 確認する点 |
|---|---|---|
| 家族分を横に並べたい | 就寝用マット | 合計幅、マット間の隙間、入口までの動線 |
| 地面から離れて横になりたい | コット | 脚の安定、寝面の高さ、側壁との距離 |
| 寝ていると背中側が冷える | 断熱性のあるマットと寝袋の組み合わせ | R値の試験条件、寝袋の温度表示、服装 |
| 荷物を小さくしたい | 実際の収納寸法で比較 | 厚手マットがコットより小さいとは限らない |
| 一人で家族分を片付ける | 収納を試せる製品 | 組み立てと排気を含む片付けの手順 |

初めてなら、手持ちの寝袋とマットで何が不足しているかを整理してください。背中の硬さ、寒さ、狭さ、片付けの負担では、買い足すものが変わります。

## コットとインフレーターマットの違い

| 比較項目 | コット | インフレーターマット |
|---|---|---|
| 体を支える構造 | フレームと張った生地 | フォームと空気 |
| 設置 | 脚の接地とロックを確認 | バルブを操作し、必要に応じて空気を追加 |
| 片付け | フレームを分解・折りたたむ | 空気を抜いて巻く・たたむ |
| テントとの相性 | 寝面が上がるため、床面積に加えて高さが必要 | 幅・長さ・厚さとバルブの位置を確認 |
| 寒さへの備え | 寝面の下の空間だけで断熱性能を判断しない | 厚さだけでなく断熱性能を確認 |
| 破損時の確認 | フレーム・脚・生地と補修部品 | バルブ・生地と修理対応 |

コットなら傾斜がある場所でも水平になる、ということはありません。平らで安定した場所に設置し、脚が沈み込まないかを確かめます。マットも「どんなテントにも入る」わけではなく、空気を入れた状態での寸法確認が必要です。

## 家族4人なら、寝床の幅と撤収まで考える

### 一人分の幅を決めてから、家族分を並べる

マットは人数分を用意するだけでは足りません。寝返りに必要な幅と、出入りする場所を残せるかを考えます。コットの場合は脚やフレームが張り出す分も確認してください。

アメニティドームLを使う方には、[家族4人分のマットサイズと敷き方](/articles/amenity-dome-l-mat-size-family-four)でシングル4枚・ダブル2枚の寸法比較をまとめています。公称寸法による計算と、テント内での実際の適合は分けて考えましょう。

### 子どもと使うなら、出入りや隙間を試す

低い位置に寝床を並べたい家庭では、マットを先に検討しやすいと考えます。ただし、マットなら事故が起きないわけではありません。隙間や段差、寝床からの出入り、周囲に置く荷物まで、実際の配置で確認してください。

コットを選ぶ場合は、対象者や使い方を取扱説明書で確認します。大人用の耐荷重表示だけで、子どもにも適するとは判断できません。

### 一枚の重量より、家族分の積載と作業を見る

厚手のマットは寝床を整えやすい一方、収納袋も大きくなります。コットは排気が不要ですが、家族分の組み立て・分解が必要です。車に積めるかに加え、誰が何枚片付けるかまで決めておくと選びやすくなります。

袋に戻す作業で困っている場合は、[マットの空気抜きと家族分の片付け方](/articles/inflatable-mat-storage-bag-guide)で、手順の見直しと収納袋・ポンプの選び方を確認できます。

## R値が高ければ、冬も必ず暖かい？

R値はマットの熱の伝わりにくさを示す指標です。同じ試験条件で測った製品の比較に役立ちますが、気温へそのまま換算できる数字ではありません。[AlpkitのR値の説明](https://eu.alpkit.com/blogs/develop/what-are-sleeping-mat-r-values)

「R値6なら何℃でも大丈夫」「厚さ10cmなら冬用」とは決めず、寝袋と衣類、地面の状態を含めて選んでください。R値が公表されていない製品を、断熱性がない製品と扱うこともできません。

コットにマットを重ねる方法もありますが、寝面からはみ出さないか、ずれないか、体を載せた状態で安定するかの確認が必要です。同じメーカー同士でも、自動的に適合するわけではありません。

## 買う前に試したいこと

1. 普段の寝る姿勢で横になり、肩・腰・足先の収まりを確認する。
2. テント内に人数分を置いた配置を考え、出入りする場所を残す。
3. コットの脚やマットのバルブが、寝具や荷物と干渉しないかを見る。
4. 組み立てから収納までを試し、収納袋を車に積む位置を決める。
5. 寝袋とマットを別々に選び切らず、宿泊先の条件に合わせて組み合わせる。

## よくある質問

### コットだけで冬キャンプに使えますか？

コットで地面から離れることと、断熱性が足りることは別です。冬に使うなら、製品の説明と宿泊条件を確認し、マット・寝袋・衣類を含めて準備してください。

### マットはコットより軽いですか？

製品によります。ここで紹介した厚手のマットは約2.5～2.7kgです。徒歩や登山で持ち運ぶなら、厚手のオートキャンプ向け製品を前提にせず、携行重量と収納寸法で選び直しましょう。

### どちらを先に買うべきですか？

低い寝床を家族分並べたいならマット、地面から離れた寝面が欲しいならコットが検討の出発点です。手持ちの装備で困っている点を一つずつ解消する選び方を勧めます。
