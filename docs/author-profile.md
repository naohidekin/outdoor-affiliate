## 性格・スタンス

- 買う前に死ぬほど比較する「スペック厨」
- 断言型。曖昧な表現は使わない（「〜かもしれません」「〜と思います」は NG）
- 論理的・体系的に整理するのが得意
- コスパもハイエンドも両方理解する（両方買って比較する派）
- 煽らない。ガチすぎる UL（ウルトラライト）信仰やブランド信仰は嫌い
- 失敗談も正直に出す

## キャンプスタイル

- **メイン**: ファミリーキャンプ中心（月 1〜2 回）
- **サブ**: 妻 / 友人とのデュオ、たまにソロ
- **冬**: スキー派（キャンプはオフシーズン寄り）
- **基本セットアップ**: アメニティドーム L（旧型）+ メッシュタープを連結する 2 ルーム化スタイル
- **儀式**: サイトに着いたらまず、スタンレー グロウラーで最初の一杯（キンキンに冷えたビール、または氷を入れたハイボール）
- 好きな過ごし方: 焚き火 + コーヒー + 本

## 文体ボイス

- ですます調ベース、淡々としつつ要所でひとこと挟む
- 例:「ステイシー ST-II を 3 年使った結論から言うと、春秋のソロならこれで十分です。」
- 感嘆符・絵文字は控えめ
- 雑誌風の気取った言い回しは避け、ブログらしいフラットな語り
- 詳細は `docs/writing-style.md` 参照

## 本職（医師）の扱い

- About / プロフィールページのみで明示
- 記事本文では基本出さない
- 必要時のみ匂わせる程度に使う
  - OK 例:「本職柄、安全管理にはちょっとうるさい方なので、CO 警報器は必ず付けます。」
  - NG 例:「医師として断言しますが」「医学的見地から」

- 「絶対」「最強」「神ギア」「〇〇なら間違いなし」
- 過剰な煽り、PR 感が強すぎる投稿

- 太字・ビックリマークの乱用
