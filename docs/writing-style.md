# 記事執筆スタイルガイド（ギア男ボイス）

CLAUDE.md の記事執筆ガイドラインをベースに、Lake & Sky リブランディング後の
あっさり清涼系デザインに合う文体ルールを定める。

---

## 基本原則

1. **ですます調ベース**。友人に話しかけるような温かみを持たせる
2. 断言一辺倒にしない。「個人的には〜」「3年使った結論から言うと〜」型を優先
3. 太字・記号装飾は最小限。文章そのもので説得する
4. 一人称は **「僕」** を基本（「私」「俺」は使わない）

## トーン

- **OK 例**:
  > ステイシー ST-II を 3 年使った結論から言うと、春秋のソロならこれで十分です。
  > 雨が読めない時期はもう一段上のテントを足すことになります。
- **NG 例**:
  > ステイシー ST-II は最強のソロテントです！絶対買って損なし！

## NG ワード（厳守）

| カテゴリ | NG | 代替 |
|---|---|---|
| 過剰断定 | 絶対 / 最強 / 神ギア / 間違いなし | 「〜なら十分」「〜が一番落ち着く」 |
| 不確実 | 〜かもしれません / 〜と思います | 断言できる内容は断言する |
| 抽象賛美 | 素晴らしい / 最高の | 具体スペックで示す |
| 煽り | 今すぐ買え / 売り切れ必至 | 「気になる方はチェックを」 |
| 医師肩書き | 医師として断言します / 医学的見地から | （基本使わない。匂わせは可） |

## 強調ルール（Lake & Sky デザイン準拠）

- **太字は 1 記事 5〜8 箇所まで**。キーセンテンスのみ
- 連続太字（3 文連続で太字を含む等）は禁止
- 色つきは青系 1 色のみ（グローバル CSS で .prose strong に色指定）
- マーカーは淡青背景（bg-blue-50 相当）を要所で
- 引用（blockquote）は左に太めの青ボーダー + 淡青背景

```

（基礎知識を 200〜400 字でサラッと）

（必要なら Markdown テーブルで概念整理）

---
```

## 画像差し込みルール

- カバー画像（H1 直上）必須
- 各 H2 セクション冒頭に情景画像 or 商品画像を 1 枚
- 本文中にも 2〜3 枚（情景・使用感画像）
- キャプションは小さい灰色テキストで出典を明記
- 詳細は `docs/image-guidelines.md`

## X ポスト引用ルール

- 1 記事あたり **2〜5 個** の X ポスト引用を埋め込む
- 配置目安: リード直後 1 個、製品セクションで使用者ポスト 1〜2 個、まとめ前 1 個
- 自分のポスト（@camp_gear_lab 等）は「実際にキャンプに行っている」証拠として
- 詳細は `docs/xembed-usage.md`

## 比較表使い分け

- **実際の商品スペック比較** → `{{comparison:id1,id2,...}}`
- **概念的な比較**（封筒型 vs マミー型 等） → Markdown テーブル

## 口コミ・レビュー

- 各商品 2〜3 件、楽天 / Amazon レビューから要約
- 一字一句の転載は避ける
- 良い点だけでなく注意点も載せる
- 末尾に「楽天で口コミをもっと見る →」アフィリエイト CTA

## ギア男の自己言及

- 愛用ギアは必ず `docs/author-gear.md` から引用
- 「僕の」「うちの」「3 年使った」等の一人称言及で人格を出す
- 失敗談・買い替え遍歴を時々混ぜる
- 本職（医師）はプロフィール / About のみ。記事内では匂わせ程度

## 文末の統一

- 「〜です。」「〜ます。」を基本とする。体言止め・断言型は使わない
- 「〜だ。」「〜である。」のコラム調混在は避ける（既存記事は順次刷新）
- 結論部分も「〜がおすすめです」「〜が一番だと思います」のですます調で統一

## CTA トーン

- 押しつけがましくしない
- 「気になる方はチェックを」程度
- 「今すぐ」「絶対」は禁止

---

## 既存記事の刷新フェーズ

1. ランドロック vs ランドネストシェルターをサンプル刷新（最初）
2. レビュー → 承認後、他記事に展開
3. 刷新時の同時改修項目:
   - 文体（ですます調 + ギア男一人称）
   - 太字の整理（5〜8 箇所まで削減）
   - カバー画像 + H2 セクション画像追加
   - X ポスト引用 2〜5 個追加
   - 愛用ギア言及を `author-gear.md` に整合
