# Sense（センス）定義 — camp-gear-lab 記事品質の第6軸

## 原則：半歩先

センスが良いとは、相手の予想の半歩だけ範囲外のことを示すこと。
- 一歩も二歩も先に行くと理解されず、半歩以内だと凡庸になる
- 情報の羅列でも逆張りでもなく、相手が薄々感じていたことを鮮やかに言語化する
- 角度・余白・願いを意識して形にする

## AI軸との違い

- AI軸（Anti-AI）= **引き算**。AI臭さを消す。「AIとバレない」が合格
- Sense軸 = **足し算**。人間にしか出せない魅力を載せる。「もっと読みたい」が合格

## 4つの構成要素

### 1. 提案力（半歩先の切り口）

読者が「そういう視点なかった」と思うギア提案・切り口が記事に1箇所以上ある。
「みんなが比較するA vs B」ではなく、「実はCという選択肢もある」「Aを選ぶ人が見落としている条件」のような角度。

行動チェック:
- 記事内に「読者が検索では辿り着けない視点」が1箇所以上あるか
- ギア男の10年の経験・医師の目線など独自の立場から生まれた提案か
- 情報の羅列ではなく、「だからこう選ぶべき」という結論に繋がっているか

### 2. 品格・洗練度

AI臭さ排除の次のレベル。「読んでいて気持ちいい」品質。
文章のリズム、段落の長短のメリハリ、余白の使い方。

行動チェック:
- 3文以上同じリズム（同じ文字数、同じ文末パターン）が連続していないか
- 説明過多になっていないか（書かないことで伝わる部分を削れているか）
- 記事全体を通読したとき「読み心地がいい」と感じるか

### 3. ブランド世界観

camp-gear-labとしての一貫した美学・トーンが記事から伝わるか。
「スペック厨だけど押しつけがましくない」「友人に教える温度感」の世界観。

行動チェック:
- 記事の結論部分にギア男の価値観（コスパ重視 / 家族優先 / 実使用重視）が反映されているか
- 他のアフィリエイトサイトと同じ結論・同じ構成になっていないか
- 「このサイトだからこそ読む価値がある」と感じるか

### 4. 言葉選び

言葉のチョイスそのものにセンスがあるか。
具体的で体温のある言葉を選ぶ。

行動チェック:
- 抽象的な形容詞（便利・快適・最適）を具体的な描写に置き換えているか
- 読者の記憶に残るフレーズが1記事に1-2箇所あるか
- 商品の良さを「スペック」ではなく「使った場面」で語れているか

## 採点基準（1-5点）

| 点 | 基準 |
|----|------|
| 1 | 4つの行動チェックをほぼ満たさない。他のアフィサイトと区別がつかない |
| 2 | 1要素のみ部分的に満たしている。全体的に凡庸 |
| 3 | 2要素以上を満たしている。camp-gear-labらしさが感じられる |
| 4 | 3要素以上を高いレベルで満たしている。読んでいて引き込まれる |
| 5 | 4要素すべてが高水準。「このサイトをブックマークしたい」と思わせる |
