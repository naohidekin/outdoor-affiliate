# 2026-09-05 改修と記事の差し替え案

トップページは、比較記事・長期使用の記録・季節の準備を入口に変更した。著者の肩書きに加え、道具を選ぶ基準と、実際に使ってきた記録へ進める構成にしている。

## コードに実装した変更

- トップページの再構成、季節リンクの切り替え、表示する記事だけの商品取得。
- PC・スマートフォンのナビゲーション、キーボードフォーカス、商品写真が切れないカード。
- CTAの自動順位を廃止。ランドロック比較は `src/lib/articleEditorial.ts` の用途・理由・注意点を表示し、使用した限定版と販売リンクの通常版を区別。
- 商品データの並び順を推薦の根拠にしない。明示的な `{{ranking:...}}` の順位は維持し、商品タグがない記事には順位のない一覧を一度だけ表示。
- クーラー比較の飲料ボトルや、テント記事の周辺機器をメインの比較画像・CTAに混ぜない。3モデル以上の比較で先頭2モデルだけのVS画像を作らない。
- 主要仕様の優先順、日本語ラベル、空欄・重複項目の処理を共通化。根拠や評価方法が登録されていない星評価を商品カード・一覧・比較表から除く。元の評価データは保持。
- 既存の販売店リンク、価格帯による販売店順、クリック計測は維持。

## 記事の差し替え案

`manifest.json` の各エントリは、記事slug、本文ファイル、差し替えるFAQ・概要・商品ID、参照資料を含む。公開サイトや `data/articles.json` には自動適用しない。

| 記事 | 差し替えの要点 | 必要な確認 |
|---|---|---|
| 子連れキャンプの虫よけ | 成分の年齢基準を本文とFAQで統一。蚊帳・スプレー・シールの一律ランキングを取りやめ、用途別の選び方へ。確認できない体験と口コミ引用を削除 | 監修医・著者による内容確認 |
| アメニティドームLの10年レビュー | 愛用ギア正本をもとに、2026年7月の買い替えと8月の初張りを反映。正本にない修理・計測・旅先の体験を削除 | 著者による体験・表現の確認 |

医学原稿は `docs/repellent-age-standard.md` とメーカーの公開情報を参照した。新しい原稿が医師確認済みであるとは扱わない。`src/lib/medical-review-gate.mjs` の公開前確認の方針を維持する。

## 本番反映

1. PRのコード差分を確認する。既存のNext.js/Vercelの公開経路を使用する。
2. 原稿の確認後、Supabaseから対象記事の最新本文・FAQ・商品IDを取得して差分を照合する。manifestの `baseSnapshotUpdatedAt` はGit内スナップショットの時刻で、本番の最新時刻を保証しない。
3. 管理画面または既存の更新APIで、対象記事の本文とmanifestの `fields` を一緒に反映する。記事ID・slug・公開日時・最新の運用メタデータは維持し、更新日時は反映時刻にする。医師アドバイス欄とも整合を確認する。
4. 本番から記事のスナップショットを取得し直し、変更した記事だけをGitへ保存する。古い `data/articles.json` 全体を本番へ上書きしない。

`scripts/sync-content-only.mjs` は本文しか更新しないため、この差し替えには単独で使わない。特に虫よけ記事のFAQと商品IDが旧内容のまま残る。既存の全件同期のチェックを省略するフラグも使わない。

## 確認と効果測定

変更時は型チェック、本番用ビルド、既存テストと新しい編集表示のテストで確認する。新しいテストは推薦順序の独立性、クーラーへの周辺商品の混入、季節導線のリンク、空欄と日本語仕様の処理を対象とする。第2弾のスマホ改善とブラウザ確認は [検証記録](../mobile-reading-2026-09-05.md) に記載。本番Supabaseを使った表示は公開前に確認する。

公開日を記録し、既存GA4のアフィリエイトクリックを同じ期間幅で比較する。記事ごとの閲覧数、販売店へのクリック率、ASPの確定報酬を併せて見る。X流入と検索流入、季節性を分けて判断し、デザイン変更による増収を事前に断定しない。今回、X投稿や自動運用の設定は変更していない。
