# X ポスト引用 利用ガイド

Outdoor Gear Lab 記事内で X（旧 Twitter）ポストを埋め込むためのガイドライン。
実装は `src/components/XEmbed.tsx`、Markdown 記法は `::xpost{...}`。

---

## 目的

1. **「実際にキャンプに行っている」リアリティの担保**
   - 自分（@camp_gear_lab 等）のポスト引用で、運営者が実在し活動している証拠を提示
2. **コミュニティ感の演出**
   - 他ユーザーの有益ポスト引用で「みんなが使っている」感を出す
3. **ギア紹介ページのリアリティ補強**
   - 使用者の実ポストでスペック表だけでは伝わらない実感を補完

## 配置の目安

| 位置 | ポストの種類 | 数 |
|---|---|---|
| リード文直後 | 自分の実フィールドポスト | 1 個 |
| 各製品セクション | 使用者の実レビューポスト | 1〜2 個 |
| まとめ前 | 自分の総括ポスト or 関連トピック | 1 個 |

合計 **2〜5 個 / 記事** が目安。多すぎる読み込み負荷と視覚的ノイズを避ける。

## Markdown 記法

```markdown
::xpost{url="https://x.com/camp_gear_lab/status/1234567890"}
```

`url` のみ必須。任意でフォールバック表示用に手書き属性を渡せる：

```markdown
::xpost{url="https://x.com/camp_gear_lab/status/1234567890" 
        author="ギア男" 
        handle="camp_gear_lab" 
        text="ランドネストシェルター、設営20分。前室の広さに妻が感動してた。"
        date="2026-03-15"
        avatar="/images/authors/gearman.jpg"}
```

## XEmbed コンポーネント仕様

### 表示要素

| 要素 | 内容 |
|---|---|
| アバター | `avatar` 属性 or プレースホルダー（白丸 + イニシャル） |
| 表示名 | `author` |
| ハンドル | `@handle` |
| 本文 | `text` |
| 投稿日 | `date`（YYYY-MM-DD） |
| X 公式アイコン | 右上に SVG（X ロゴ） |
| 引用元リンク | カード全体 or 「X で開く →」リンクで `url` へ |

### スタイル（Lake & Sky 準拠）

- 背景: 白 #FFFFFF
- ボーダー: 1px solid #E2E8F0
- 角丸: rounded-xl（控えめ）
- 影: なし or 極薄
- 本文文字: #1A1F2E
- ハンドル: #64748B
- 「X で開く」リンク: #2B6CB0、ホバーで濃紺

### 動作

- カード全体クリック or 「X で開く →」で `url` を新規タブで開く
- `target="_blank" rel="noopener noreferrer"`
- 将来 widgets.js を有効化する余地を残すため、props で `mode="card" | "embed"` を切替可能に

## 引用元の明示

- 必ず `url` を実在のポスト URL にする
- 引用 X ポストの本文は「要約・抄録」ではなく**そのままの本文**を載せる
  （X 公式 ToS および著作権配慮）
- 著しく長い場合は「…」で省略可

## 自分のポスト引用ルール

- アカウント: `@camp_gear_lab`（仮、実アカウント確定後に統一）
- ギア男のリアルなフィールド報告 / レビュー / 失敗談を引用
- ポスト時刻と記事内の言及内容に整合性を持たせる
- 古いポスト（2 年以上前）は基本使わない

## 他ユーザーのポスト引用ルール

- 公開ポストのみ（鍵アカウント NG）
- 「これいい」「最高」だけのポストは引用しない（情報量重視）
- ネガティブ含み正直な実感のあるポストを優先
- 引用元のハンドル・本文を改変しない

## NG

- 投稿者の許可なくスクリーンショットを画像として貼る（必ず XEmbed で）
- 文脈を変えるための部分引用
- 政治・宗教・センシティブ話題のポスト引用

## 実装フェーズ

1. `src/components/XEmbed.tsx` 作成（カードモード）
2. `ArticleContent.tsx` に `::xpost{...}` パーサー追加
3. ランドロック比較記事サンプル刷新時に 3〜4 個埋め込み
4. レンダリング確認後、他記事に展開
