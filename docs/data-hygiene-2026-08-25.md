## 影響が無いと確認したもの

### 商品の categoryId は公開ページに出ない

`src/lib/db.ts:164` の `const used = new Set(articles.map((a) => a.categoryId))`
のとおり、カテゴリページは**記事の** categoryId で構成される。
商品側の categoryId が違っていても読者には見えない。
管理画面の一覧とスクリプトの絞り込みに影響するだけ。

ふるさと納税の利用券3件が `categoryId: "tarp"` になっているのは
このケース。`tarp-setup-guide-for-beginners` に載っているが、
これは「キャンプグランドで実際に練習してみるのもアリ」という
H2の文脈で施設を紹介しているもので、**配置は意図的**。
表示上の誤りではない。

### カテゴリと商品名の突き合わせ検査は使い物にならなかった

「categoryId に対応する語が商品名に無ければ疑わしい」という検査を書いたが、
111件が引っかかり、うち97件が公開記事掲載だった。中身を見ると
`NANGA オーロラテックスライト`（寝袋）、`YETI タンドラ 45`（クーラー）、
`CLAYMORE FAN V600+`（扇風機・英字なので日本語の正規表現に当たらない）など、
**ほぼ全部が誤検知**だった。

商品名に日本語のカテゴリ語が入っていないだけで分類は正しい。
この方式は捨てる。**明確に商品でないもの（利用券・ふるさと納税・
衣類）を名指しで探すほうが、精度も実用性も高い。**
