# X投稿生成スキル（SKILL.md）

## 概要

ギア男（@camp_gear_lab）のX投稿を10タイプ生成するためのトーン・フォーマット仕様。
生成スクリプト（`scripts/generate-x-posts.js`）およびプロンプトテンプレート（`src/lib/x-post-prompts.mjs`）が参照する。

---

## 共通ルール（全タイプ共通）

### 文体
- **一人称は「僕」**。体験ベースで書く（「先週使ってみたんですが」「去年これで失敗しました」）
- 基本はですます調。ただし体言止め・倒置法も使ってよい。長くなりすぎない
- 絵文字は0〜1個。顔文字は使わない
- 各投稿は280文字以内（URL・ハッシュタグ含む）
- ハッシュタグは2〜3個、本文末尾に改行して配置
- **友人に話しかけるような温かさ**を大切に。押しつけがましくなく、一緒に考える感じで

### NGワード（生成時にブロック）
- 誇大表現: 最高、最強、絶対、神、完全、100%、必ず、今すぐ
- AI定型表現: 〜してみてはいかがでしょうか、〜をご紹介します、〜についてまとめました
- 記事まとめ感: おすすめ○選、徹底比較、完全ガイド、〜についてまとめてみた
- 煽り: 見なきゃ損、知らないと損、やばい、衝撃
- 薬機法抵触: 治る、効く、改善する（doc_health_tipで特に注意）
- 医療法抵触: 診断、処方、〜すべき（医療行為の示唆）
- 景表法抵触: 業界No.1、世界初、唯一の

### トーン基準
- 友人に話しかけるような温かさ。知識はあるけど偉そうにしない
- 「個人的には〜」「3年使った結論から言うと〜」「僕はこれで失敗しました」型
- 結論は明確に伝えるが、断定一辺倒にしない。「〜がおすすめです」「〜が一番だと思います」
- 医師属性は基本伏せる。doc_health_tipのみ「本職柄〜」と匂わせる

### フックパターン（1行目が命）

インプレッションは冒頭1行で決まる。以下のパターンを積極的に使う。

| パターン | 例 | 向いているタイプ |
|---------|-----|----------------|
| **逆説型**（最もRT誘発） | 「高いテントほど後悔する、は嘘だった。」 | failure_story / article_promo |
| **数字起点型** | 「3年使った結論。」「6回失敗して気づいた。」 | gear_thread / outdoor_tip |
| **状況設定型** | 「夜中2時、シュラフから出られなくて気づいた。」 | failure_story |
| **断定転換型** | 「安いシュラフで十分。ただし1つだけ条件がある。」 | article_promo / outdoor_tip |
| **告白型** | 「高い焚き火台を買って後悔した話をする。」 | failure_story |

**逆説型・告白型を週の投稿に最低1本は入れること。** これがインプレッション底上げの最短ルート。

## タイプ別仕様

### 1. article_promo（記事紹介）
- **軸**: キャンプ | **頻度**: 週2 | **承認**: まとめ承認
- **目的**: サイトへの誘導
- **フォーマット**: 体験や感想を交えて記事を紹介。「ブログに書いた」感で
- **URL**: `https://camp-gear-lab.com/articles/{slug}?utm_source=x&utm_medium=social&utm_campaign=article_promo`
- **ハッシュタグ**: カテゴリ別（テント→#テント #ファミキャン、バーナー→#バーナー #キャンプ飯 等）
- **例**:
```
SOTOのST-310とイワタニのジュニアCB、どっちがいいか聞かれることが多いのでまとめました。

僕の答えはシンプルで、「ソロならST-310。ファミリーならジュニアCB。」です。

火力と五徳の安定感が全然違うんですよ。詳しくはリプ欄へ。
#キャンプギア #バーナー
```

### 2. outdoor_tip（豆知識）
- **軸**: キャンプ | **頻度**: 週2〜3 | **承認**: 自動承認
- **目的**: フォロワーとの接点維持・専門性アピール
- **フォーマット**: 実体験ベースの実用ネタ。教科書的にならない
- **URL**: なし
- **例**:
```
春キャンプ、昼は暑いのに夜は5℃くらいになることがよくあります。去年フリースを忘れて凍えた経験から、今は絶対に持っていくようにしました。

朝晩の寒暖差は初心者の方がいちばんハマりやすいポイントだと思います。4月でもダウンは必須ですよ。
#キャンプ #春キャンプ
```

### 3. poll_question（アンケート・質問）
- **軸**: 全軸 | **頻度**: 週2 | **承認**: 自動承認
- **目的**: エンゲージメント獲得（リプ・RT・投票）
- **フォーマット**: 二択〜四択。対立軸を明確に。自分の意見を添える
- **URL**: なし
- **例（キャンプ）**:
```
テント選びで一番重視するのはどれ？

① 軽さ（担いで歩くから）
② 設営の速さ（雨の日に差が出る）
③ 居住性（広さは正義）
④ 価格（コスパ命）

個人的には②。雨の中30分かかるテントは二度と使わない。
#キャンプ
```
- **例（AI）**:
```
コード書く時のAIアシスタント、メインで使ってるのはどっち？

① ChatGPT / Copilot
② Claude / Claude Code

最近Claude Codeに完全移行した。理由はコンテキストの長さ。
```

### 4. failure_story（失敗談）
- **軸**: キャンプ / 子育て | **頻度**: 週1 | **承認**: 自動承認
- **目的**: 共感・親近感。「あるある」でRT狙い
- **フォーマット**: オチのある短い失敗談。自虐OK。教訓を1行添える
- **URL**: なし
- **例**:
```
シュラフの「快適温度」と「限界温度」の違いを知らずに失敗した話をします。

限界温度0℃のシュラフで11月のキャンプ場に突撃して、夜中3時に寒さで目覚めて車で暖房をつけて寝ました。

快適温度＝普通に寝られる温度
限界温度＝ギリギリ耐えられる温度

これは初心者の方にぜひ知っておいてほしいです。
#キャンプ初心者
```

### 5. gear_thread（ギア深掘りスレッド）
- **軸**: キャンプ | **頻度**: 週1 | **承認**: まとめ承認
- **目的**: 専門性アピール。スレッド形式でアルゴリズム優遇（滞在時間UP）
- **フォーマット**: 3〜5ツイートのスレッド。JSON配列で生成し、tweets[0]が親ツイート
- **URL**: 最終ツイートのみ `camp-gear-lab.com/articles/{slug}?utm_source=x&utm_medium=social&utm_campaign=gear_thread`
- **構成**:
  1. 掴み（「○○を△年使った結論」）+ 🧵マーク
  2. 良い点（具体的スペックで）
  3. 悪い点・注意点（正直に）
  4. どんな人に向くか
  5. まとめ＋サイトリンク
- **生成フォーマット**: `"tweets": ["1ツイート目", "2ツイート目", ...]`
- **例（1ツイート目）**:
```
スノーピーク焚火台Lを6年使った感想をまとめます🧵

重い、片付けが面倒、値段も高い。
それでも僕がこれ以外に戻れない理由があるので、スレッドで書いていきますね。
```

### 6. ai_dev_log（AI開発日記）
- **軸**: AI | **頻度**: 週1-2 | **承認**: 自動承認
- **目的**: エンジニア・AI興味層へのリーチ。唯一性の演出
- **フォーマット**: Claude CodeやAI開発のリアルな体験。驚き・ハマりポイント中心
- **URL**: なし（将来テック記事追加時に付与）
- **トーン補足**: テック寄りだが専門用語を詰め込みすぎない。「医者がコード書いてる」面白さを出す
- **例**:
```
Claude Codeにキャンプギアの比較記事を書かせてみました。

products.jsonに50製品のスペックを入れて「この中から5つ選んでランキングを作って」と頼んだら、選定理由まで筋が通っていて驚きました。

ただし価格情報は平気で間違えるので、そこだけ人間がチェックする必要があります。
#ClaudeCode #AI
```

### 7. parenting_outdoor（子育て×アウトドア）
- **軸**: 子育て | **頻度**: 週1 | **承認**: 自動承認
- **目的**: パパママクラスタへのリーチ。ファミキャン記事への誘導
- **フォーマット**: 子供とのアウトドア体験。ほっこり〜笑える話。子供の実名は出さない
- **URL**: 関連するファミキャン記事があればリンク
- **例**:
```
子供に「今日のキャンプ何が楽しかった？」って聞いたら「マシュマロ焼いたやつ」って言われました。

2万円の焚き火台より100円のマシュマロが勝ちましたね笑

キャンプの満足度はギアの値段じゃなくて体験で決まるんだと思います。…とか言いつつ焚き火台は3台持ってるんですが。
#ファミリーキャンプ
```

### 8. doc_health_tip（医師×アウトドア健康ネタ）
- **軸**: 医師 | **頻度**: 週1 | **承認**: 必ず手動承認
- **目的**: 信頼性UP。「この人の言うこと信頼できる」感の醸成
- **フォーマット**: アウトドア×健康の実用情報。「本職柄〜」で医師を匂わせる
- **URL**: なし
- **追加NGルール**:
  - 「治る」「効く」「改善する」は使わない（薬機法）
  - 特定の薬品名・治療法の推奨は避ける
  - 「症状が続く場合はかかりつけ医に相談を」系の注意喚起を必要に応じて添える
  - 診断・処方を示唆する表現は禁止（医療法）
- **例**:
```
キャンプ場での熱中症対策、「水を飲めば大丈夫」は実は半分正解で半分間違いです。

本職柄気になるので補足させてください。水だけだとナトリウムが不足して逆に危険なことがあります。経口補水液かスポーツドリンクをそのまま飲むのがおすすめです。

特に子供は「喉が渇いた」と言わないことが多いので、親御さんが30分おきに声をかけてあげてください。
#熱中症対策 #キャンプ
```

### 9. seasonal_hook（季節・イベント連動）
- **軸**: 全軸 | **頻度**: 週1 | **承認**: まとめ承認
- **目的**: トレンド便乗。検索・おすすめTL露出
- **フォーマット**: GW・梅雨・セール・天気等に連動。タイムリーさが命
- **URL**: 関連記事があればリンク
- **参照データ**: `data/rakuten-sale-calendar.json`, `data/amazon-deal-calendar.json`
- **例**:
```
GWのキャンプ場、予約は3月で埋まってる。今から探すなら穴場は平日月曜泊。

金土はどこも満杯だけど、月曜なら直前キャンセルが出やすい。あとは市営・県営のキャンプ場。予約システムが古くてネット予約できない分、競争率が低い。
#GWキャンプ #キャンプ場
```

### 10. repost_rewrite（リライト再投稿）
- **軸**: 全軸 | **頻度**: 週0-1 | **承認**: まとめ承認
- **目的**: 過去資産の再活用。ネタ消費ゼロ
- **フォーマット**: 過去の反応良い投稿を表現を変えて再投稿。コピペ厳禁、必ずリライト
- **選定基準**: インプレッション上位 or いいね数上位の過去投稿
- **ルール**: 元投稿から30日以上経過していること

## 承認区分まとめ

| 区分 | タイプ | 条件 |
|------|--------|------|
| 自動承認 | outdoor_tip, poll_question, failure_story, ai_dev_log, parenting_outdoor | NGチェック全passかつURLなし |
| まとめ承認（週1） | article_promo, gear_thread, seasonal_hook, repost_rewrite | リンク含む or 連投 |
| 必ず手動承認 | doc_health_tip | 医療情報のため常に手動確認 |
