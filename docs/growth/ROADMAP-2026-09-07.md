# Camp Gear Lab：90日実行ロードマップ

期間：2026-09-07〜2026-12-05。最終更新：2026-09-07。

## 方針

「子ども連れキャンプの具体的な困りごとを、購入前に解決する」サイトへ育てる。既存の検索流入からの収益改善を先に行い、動画と有料コンテンツは小さく検証する。収益額・注文原票・個別アクセス統計は公開リポジトリに保存しない。収益目標はオーナーとの非公開会話で管理し、達成を保証しない。

小児科医・二児の父という背景は、出典のある知識と確認できる実体験で示す。所有・使用・測定を確認できない一人称レビューは追加しない。子どもの健康に必要な情報は無料記事に残し、有料商品は準備の手間を減らすテンプレートを中心にする。

既存の寝袋改訂、家族向けガイド、クリック計測は再実装しない。公開記事はDBが正本であり、Git内のMarkdown更新だけでは公開本文に反映されない。

## 計測と判断

| 指標 | 定義・注意 | 判断に使うもの |
|---|---|---|
| 確定報酬 | Amazon・楽天・ASPの承認済み報酬。返品・取消・確定遅れを区別 | 売上拡大の主指標 |
| 記事からの購入先クリック | 既存イベントで記事・商品・配置を確認。購入とは呼ばない | 導線の改善 |
| クリックしたセッション率 | 計測可能なら、購入先クリックを含むセッション／対象記事の流入セッション | 流入量の差を考慮した比較 |
| イベント数／セッション | セッション単位の集計が不可の場合の代替。確率・購入率と混同しない | 導線利用の傾向 |
| EPC | 同じASP・同じ集計定義の確定報酬／クリック数。GA4とASPの母数を混ぜない | 提携先の比較。確定遅れを注記 |
| SNS流入 | UTM別の流入・購入先クリック。再生数だけで評価しない | 制作時間を増やすか |
| note | 商品閲覧・有料購入・手数料控除後売上・制作時間 | 商品を増やすか |

基準は取得可能な直近の完全な28日間を記録する。変更日を残し、改訂後の同期間を比較する。季節性が大きいため、夏クーラーと秋冬用品をまとめた増減だけで改訂の効果を断定しない。件数が少なければ検証を延長し、クリック増を報酬増と取り違えない。

10/4は計測・導線の確認を中心に、11/1は記事別傾向、12/5は確定報酬と制作時間を含めて判断する。比較に十分なデータがない施策は「効果未判定」と明記する。

## 集客・新商材の試験条件

- 動画はYouTubeを先行。Shortsから関連動画・プロフィールを経由する導線を設計し、通常の説明欄URLだけに依存しない。Xは記事告知の反復だけでなく、実物の違い・失敗回避・選び方を投稿原稿にする。
- TikTokは同じ素材を再利用でき、アカウントのリンク・Shop等の条件を確認できた段階で試す。専用の制作体制は先に作らない。
- noteは1商品で試す。価格案は1,000円。一般的なおすすめ商品の羅列ではなく、家族に合わせて編集できる準備キットを販売する。月額会員制度は初回試験に含めない。
- 新商材は携帯トイレ・足元灯・マット・電気毛布・電源・レンタルから優先。実物検証が必要なものは既存の所有品・写真から始める。
- 追加の機材購入・有料サービス契約をこの計画だけで実行しない。費用が必要なら具体的な成果物と費用を提示する。

## 完了条件

- 記事：出典・型番・購入先確認 → DBへ保存 → 公開ページで内容と主要リンク確認 → 改訂記録保存。
- コード：必要なテスト・ビルド → Git反映 → デプロイ結果と本番確認。スマホで横はみ出し、比較表、購入ボタンを確認する。
- 提携：申請準備と承認を別状態で記録。公開されている料率を自身の契約料率とみなさない。
- SNS・note：制作完了と公開完了を分ける。原稿ができただけで流入・売上を報告しない。
