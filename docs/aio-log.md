## 収益分析からの改善（2026-07-12 第5弾）

外部レビューで判明した事実と対応:

**計測の真実**: GA4キーイベント(37)＜自前クリック(202)の乖離は「バグ」ではなく、
gtag(Googleドメイン)が広告ブロッカーで欠落するため。**ファーストパーティのsendBeacon
計測(202)の方が正確**。GA4は構造的に過少計測。→ 自前計測を主軸に据える方針。

**実施**:
1. **計測にplacement軸を追加**: アフィリクリックに「ボタン位置」(product_card/ranking/
   comparison_table/recommended/body_text)とproduct_nameを記録。「商品が弱い」か
   「ボタン位置が弱い」かを切り分け可能に。管理画面/admin/affiliateに位置別内訳を表示。
   ※Supabaseで `scripts/sql/add-affiliate-click-columns.sql` を実行後に有効化
2. **ランドロック比較記事に収益導線**: 最も読まれ(2分12秒)キーイベント0だった記事に、
   冒頭の条件別推奨表＋3つの結論直下に商品カード(ボタン)を追加。本文32000字は温存
3. **低CTR記事のタイトル改稿**: single-burner / gas-lantern に「結局どれ？」「LED時代になぜ？」
   の意思決定フックを追加(位置10でCTR1%台→改善狙い)
4. **クーラーボックス記事**: 冒頭表の直後に主要2モデルの即決カードを追加(ボタンが下部偏在の是正)

**収益構造の把握**: 上位4記事(ファミテン38/扇風機27/ソロテント20/LEDランタン18)で
全クリックの51%。少数記事集中型は健全。→ 無差別量産より4領域の深掘りが正解。
Amazon58% / 楽天41%で楽天も十分機能 → 現構成(両建て)を維持。

**要ユーザーデータ(収益性確定に必要)**: アフィリ管理画面の集計期間、Amazon/楽天の
注文数・売上・報酬額、記事別トラッキング。→ これが揃えばEPC・セッションRPMで
記事の真の収益性を比較できる(クリック数だけでは判断不可)。
