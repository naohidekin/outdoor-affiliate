# ギア男 リプ対象リスト（URLを貼るだけ）
# 使い方: このファイルを reply-targets.txt にコピーし、返したいツイートのURLを1行ずつ貼る
#   cp data/x/reply-targets.example.txt data/x/reply-targets.txt
#   npm run x:v2:reply
# 本文はURLから自動取得します（fxtwitter, 認証不要・$0）。
# 軸を指定したい時だけ「URL | doctor」のように後ろに付ける（省略時は camp）。
# 自動取得できない時だけ「URL | 軸 | 本文」で本文を手打ちしてもOK。
#
# 例（下の2行は説明用。実際の返したいツイートURLに差し替えてください）:
https://x.com/sino_camp/status/2073394166869155857
https://x.com/someone/status/1234567890 | doctor
