# おにやんま君×パワー森林香レビュー｜虫嫌いの家族キャンパーが3シーズン使った正直な感想

![木漏れ日の森 — こんな場所でキャンプするなら虫除けは必須](https://images.unsplash.com/photo-1441974231531-c6227db76b6e?w=1200&h=600&fit=crop&crop=center)

3年前の夏、長野の高原キャンプ場でブヨに足首を10箇所やられました。翌朝、パンパンに腫れた足首を見て「もう二度とこんな目に遭いたくない」と本気で虫除けを見直したのが、今の装備にたどり着いたきっかけです。

森林香は10年箱買いし続けてます。赤い箱を見るとキャンプシーズンが来たなと思う。もはや夏の風物詩。おにやんま君を追加してからは夏キャンプの虫ストレスがさらに減りました。ただし万能じゃないです。蚊にはおにやんま君だけだと心もとないし、森林香も風向き次第で効果が薄れる。この記事では、森林香10年・おにやんま君3シーズン、家族キャンプで使い続けた僕の正直な感想を、効いた場面・効かなかった場面もあわせて書いていきます。

## なぜおにやんま君 + パワー森林香なのか

キャンプの虫除けというと、まず思い浮かぶのはスプレーですよね。もちろんスプレーも使いますが、うちの子供が「ベタベタするから嫌」と塗り直しを拒否するんです。2時間おきに塗り直さないと効果が切れるのに、遊びに夢中の子供を捕まえるのは至難の業。

そこで僕がたどり着いたのが「二段構え」の考え方です。

- **おにやんま君 = 物理的忌避（視覚）**。薬剤を一切使わず、天敵であるオニヤンマの姿で虫を近寄らせない
- **パワー森林香 = 空間防御（煙による忌避＋殺虫）**。メトフルトリンの煙でサイト全体をカバーする

「近寄らせない＋来たら倒す」。この組み合わせが、スプレー単体に頼るよりずっと快適でした。スプレーは人体に直接塗る「最終防衛ライン」として残しつつ、サイト全体を面で守る発想です。

```
【僕のサイトでの配置イメージ】

        風向き →

   [おにやんま君]     [おにやんま君]
          ┃                    ┃
     ┌────┸────────────────────┸────┐
     │          タープ下             │
     │    テーブル     チェア        │
     │                              │
     └──────────┬───────────────────┘
                │
          [おにやんま君]
                │
     森林香（風上）        [テント]

     森林香 = パワー森林香（携帯防虫器に入れて吊るす）
```

## おにやんま君 徹底レビュー

![サンライン おにやんま君](https://thumbnail.image.rakuten.co.jp/@0_mall/aorinetshop/cabinet/23-leisure11/010-97084.jpg?_ex=400x400)

### 基本情報

正直に言います。初めておにやんま君を見た時は「こんなおもちゃで虫が来なくなるわけないだろ」と思いました。リアルなトンボの模型で、翅の透明感まで再現されてるんですが、いやいやこれで虫除け？と。サンライン版やストラップ版など複数バリエーションがあって、キャンパーの間では定番の虫除けグッズになってます。

| 項目 | 内容 |
|------|------|
| メーカー | サンライン（SUNLINE）ほか |
| タイプ | 安全ピン / ストラップ |
| 価格（目安） | 約1,000〜1,800円 |
| 素材 | 樹脂製（翅は0.5mm厚） |
| 薬剤 | 不使用 |

### 効果を感じた場面

一番わかりやすかったのが、**タープのポールに吊るした時のアブの減少**です。以前は夏場にタープ下でアブが2〜3匹飛び回ってたんですが、おにやんま君を設置してからは明らかに飛来数が減りました。完全にゼロじゃない。でも「あれ、今日は来ないな」と思う日が明らかに増えた。

帽子に付けて散策すると、顔周りにまとわりつくハエやアブが減ります。これは体感としてはっきりわかる。

そして意外だったのが、**子供が面白がって自分から付けたがること**。トンボの模型がリアルなので、うちの息子がこれ見て「虫除けの勇者だ！」って言ってたのは笑いました。帽子に付けて得意げに歩き回ってます。虫除けを嫌がる子供が自発的に対策してくれるのは、親としてはめちゃくちゃありがたい。

### 効かなかった場面

正直に書きます。**蚊にはあまり効果を実感できなかった**。蚊はCO2（二酸化炭素）や体温に反応して寄ってくるので、見た目でビビらせる作戦が通じないんだと思います。蚊対策は森林香やスプレーに頼るしかないです。

**夜間も効果は薄い**と感じてます。暗くなると虫がおにやんま君を見えなくなるので、当たり前といえば当たり前。夜は期待しないほうがいい。

あと、**風が強い日**はそもそも虫が少ないので、おにやんま君のおかげなのか風のおかげなのか正直わかりませんでした。

### 使い方のコツ

3シーズン使ってわかったポイントです。

1. **目線の高さ（150cm前後）に設置する**。地面近くだと虫の視界に入りにくい
2. **複数個を離して配置する**。サイトの四隅のタープポールに1個ずつ吊るすのが理想
3. **クリップが弱いのでカラビナで補強する**。純正クリップだけだと風で落ちます。小さなカラビナを1つ噛ませるだけで安定する
4. **専用ケースを使って持ち運ぶ**。翅が薄い樹脂製なので、ザックに直接入れると割れます

**口コミ（要約）**

> 「登山で帽子に付けたら、いつも顔の周りを飛んでいた虫がほとんど来なくなった。蚊には効かないけどアブには確実に効いている」（40代男性・登山利用）

> 「キャンプで4個買ってタープの四隅に付けている。体感で虫の飛来が半分以下になった」（30代男性・ファミリーキャンプ）

> 「子供のリュックに付けたら喜んで背負って歩くようになった。アクセサリーとしても気に入っている」（30代女性・親子ハイキング）

## パワー森林香 徹底レビュー

![富士錦 パワー森林香（赤色）30巻入り](https://thumbnail.image.rakuten.co.jp/@0_mall/kodamaichiba/cabinet/katorisenkou/428618.jpg?_ex=400x400)

### 基本情報

パワー森林香は、児玉兄弟商会が製造する屋外専用の防虫香です。赤い箱が目印。一般的な蚊取り線香とは完全に別物で、有効成分メトフルトリンを高濃度で配合した「プロ仕様」の防虫線香です。キャンパーや林業関係者の定番。

僕はキャンプを始めた10年前からずっとこれ一筋です。毎年シーズン前に箱買いして、赤い箱がAmazonから届くと「ああ今年も夏が来るな」ってなる。もう完全に季節の風物詩。

### パワー森林香 vs 普通の蚊取り線香

| 比較項目 | パワー森林香（赤） | 普通の蚊取り線香 |
|---------|-------------------|-----------------|
| 有効成分 | メトフルトリン（高濃度） | アレスリン |
| 煙量 | かなり多い（体感で2〜3倍） | 標準 |
| 線香の太さ | 太い（約2倍） | 標準 |
| 燃焼時間 | 約5〜6時間 | 約7時間 |
| 1巻コスト | 約40〜55円 | 約15〜25円 |
| 屋外での効果 | 強い（広範囲） | 弱い（風で流れる） |

燃焼時間は普通の蚊取り線香より短いですが、太い分だけ煙の量と有効成分の放出量が段違い。屋外ではこの「煙の壁」が効きます。

### 効果を感じた場面

**夕方のテーブル周り**がわかりやすいです。夕方4時〜6時のいわゆる「ブヨタイム」に森林香を焚くと、テーブル周辺の蚊やブヨが明らかに減る。

タープ下に吊るして使うと、煙が天井面に沿って広がって、まるで「結界」みたいにサイト全体を守ってくれます。この使い方が一番好き。

朝食時のブヨ対策にも効きました。長野の高原キャンプ場は朝のブヨがひどいんですが、朝食準備の30分前に点火しておくと、食事中はほぼ快適。この匂い嗅ぐと夏キャンプだなーって思います。独特の匂いなんですけど、10年も使ってると完全に「夏の匂い」になってる。不思議なもんです。

### 注意点

- **煙が多いので、近すぎると衣類に匂いがつきます**。テーブルから1.5〜2m離して設置するのがベスト
- **テント内での使用は絶対にNG**。一酸化炭素中毒の危険があります
- **子供やペットの手が届かない場所に設置してください**。線香自体がかなり高温になる
- **専用ホルダーがないと使いにくい**です（後述）

### 携帯防虫器（専用ホルダー）の必要性

![児玉兄弟商会 携帯防虫器（森林香専用ケース）](https://thumbnail.image.rakuten.co.jp/@0_mall/kodamaichiba/cabinet/katorisenkou/428620.jpg?_ex=400x400)

これがまたよくできてるんですよ。吊り下げフック付き・灰受け付きで、タープポールやベルトに掛けて使えます。予備の線香を収納できるスペースもある。

## コスパ計算：1キャンプあたりいくら？

虫除けグッズは消耗品なので、ランニングコストも気になりますよね。僕の使い方で計算してみました。

| アイテム | 購入価格 | 1泊の使用量 | 1泊コスト |
|---------|---------|------------|----------|
| おにやんま君（×4個） | 約4,000〜7,000円 | 繰り返し使用 | 0円 |
| パワー森林香 30巻 | 約1,300円 | 2巻 | 約87円 |
| 携帯防虫器 | 約700〜1,000円 | 繰り返し使用 | 0円 |
| **合計** | **約6,000〜9,000円** | — | **約87円/泊** |

おにやんま君4個は初期投資としてはやや大きいですが、壊れない限り何シーズンでも使えます。安いモデルなら1個1,000円前後。僕のおにやんま君は3シーズン目で翅が1枚折れたけど、まだ現役。森林香30巻で15泊分。月1〜2回のキャンプなら、ワンシーズン（5〜9月）で1箱使い切るペースです。蚊取り線香を買い足す感覚と大差ないコスト感ですね。

## 僕の実際の使い方（ファミリーキャンプでの運用）

アメニティドームL＋メッシュシェルターの構成で、いつもこんな感じでやってます。

1. **サイト到着 → おにやんま君をタープポール4箇所に設置**。カラビナで吊るします。目線の高さ（150cm前後）を意識。虫の視界に入るように配置する

2. **テーブルセット完了 → 風上にパワー森林香を点火**。携帯防虫器に入れて、テーブルから2mほど風上側に吊るす。風向きが変わったら位置を調整

3. **子供にはイカリジン配合スプレーを塗布**。虫除けスプレーの選び方や塗り方のコツは[キャンプの虫除け完全ガイド](/articles/camp-insect-repellent-guide)にまとめています

4. **夕方のブヨタイムに2巻目を追加点火**。16時頃から虫の活動が活発になるので、ここで煙の壁を厚くする

5. **就寝前に森林香を消火、テント内はメッシュで防御**。テント内に火気を持ち込むのは厳禁。アメニティドームLのメッシュインナーを閉じれば、テント内に虫が入ることはほぼない

この5ステップで、夏場の1泊キャンプを快適に過ごせてます。3年前にブヨにやられた足首の傷跡を見るたびに、「あの時からちゃんと対策しておけば」と思う。でも今は虫のことをほとんど気にせずキャンプを楽しめるようになりました。

## もし刺されてしまったら

どんなに対策しても、完全にゼロにはできません。僕の経験では、ブヨに刺された直後は流水で患部を洗い、ステロイド軟膏を早めに塗るのが腫れを抑えるコツです。掻きむしると跡が残るので、子供には特に注意してあげてください。

腫れが3日以上ひどくなり続ける場合や、刺された後に全身の蕁麻疹・息苦しさが出た場合はすぐに受診してください。

## よくある質問

**Q. おにやんま君は蚊に効きますか？**
A. 正直、蚊への効果は実感できてないです。蚊はCO2や体温に反応して寄ってくるので、見た目でビビらせるのが通じない。蚊対策は森林香やスプレーで補ってください。

**Q. パワー森林香と普通の蚊取り線香の違いは何ですか？**
A. 有効成分メトフルトリンの濃度と煙量が段違いです。線香の太さが約2倍あり、風のあるキャンプ場でも煙が途切れにくい。屋外での防虫効果は普通の蚊取り線香とは比べものにならないです。

**Q. おにやんま君の寿命はどのくらいですか？**
A. 僕は3シーズン使って翅が1枚折れた程度です。樹脂製なので経年劣化はありますが、持ち運び時にケースに入れておけば数年は使えます。

**Q. パワー森林香はテント内で使えますか？**
A. 絶対にダメです。一酸化炭素中毒の危険があります。屋外専用と割り切ってください。就寝時はメッシュインナーで物理的に虫を防ぎましょう。

**Q. おにやんま君と森林香、どちらか一つだけ買うならどっち？**
A. パワー森林香です。蚊・ブヨ・アブの全方位に効くし、即効性も高い。おにやんま君はアブ・蜂には効くけど蚊には弱いので、まず森林香＋スプレーで基盤を作って、余裕があればおにやんま君を追加するのがおすすめです。

**Q. パワー森林香は2シーズン目も継続購入すべき？1箱でどれくらい持ちますか？**
A. 続けて買う価値があります。30巻入りで1泊2〜3巻使うとすると、月2回のキャンプで約5〜7ヶ月分。一般的なキャンプシーズン（5〜9月）なら1箱でちょうど使い切るペースです。定価は約1,300円。1泊あたり約87〜130円なので、虫除け対策のコストとして迷う金額じゃないと思います。2シーズン目は携帯防虫器があるので本体代だけです。
